## Independent defect evidence and fixes

- **F1 / AC5:** Baseline real-PostgreSQL reproduction made an unknown post-write `23514` child-row trigger on each of
  `workout.performAgain`, `routine.startWorkout`, and `workout.saveAsRoutine` become durable `invalid_state`; identical
  retry after removing the fault returned duplicate rejection. No partial roots/children/reservations/revisions/active
  changes/cursor/batch were observed. Contract requires unexpected infrastructure failure to be a sanitized top-level
  500 with no replay evidence, then the unchanged retry to execute. The preserved test is
  `unknownPostWriteCheckConstraintIsInfrastructureFailureForAllCopyCommands`; Worker’s narrow executor classifier now
  rethrows unknown integrity failures while retaining exact known domain signatures. Worker’s final targeted 89-test run
  and QA’s targeted/full runs independently passed the regression and retry assertions.
- **F2 / AC3:** `workoutRootIdCannotClaimAnIdReservedForAnExistingWorkoutChild` originally observed HTTP 500
  `internal_error` twice instead of rejected `id_collision` then duplicate `id_collision`; no partial state or replay
  evidence was written. V3 shared workout-family root/child reservations make this a domain collision. Worker’s narrow
  `23505` + exact `child_id_reservations_pkey` classifier fixed it. Final Worker and QA targeted/full runs passed HTTP
  status, code, replay, and no-effect assertions. Both initial red reproducers remain in the final test file; no
  production test seam was added.
